# ประเทศไทยพร้อมรับมือกับ AI หรือยัง?

เว็บไซต์นำเสนอที่สร้างจากสไลด์ต้นฉบับ (12 หน้า) เป็น HTML/CSS/JS ล้วน ไม่ต้อง build

## เปิดในเครื่อง
ดับเบิลคลิก `index.html` (ฟอนต์ Prompt/Sarabun โหลดจาก Google Fonts ถ้าออฟไลน์จะใช้ฟอนต์ไทยของระบบแทน)

## โหมดพรีเซนต์
กดปุ่ม "โหมดพรีเซนต์" แล้วใช้ ← → / PageUp / PageDown / Space เปลี่ยนหน้า, F = เต็มจอ, Esc = ออก (มือถือปัดซ้าย-ขวาได้)

## นำขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `ai-thai-law`)
2. อัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมดไปที่รากของ repository
   ```
   git init
   git add .
   git commit -m "Add presentation site"
   git branch -M main
   git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ repo>.git
   git push -u origin main
   ```
3. ที่ Settings → Pages เลือก Source = "Deploy from a branch", Branch = `main`, Folder = `/ (root)`
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## แหล่งข้อมูล
เนื้อหาและตัวเลขทั้งหมดมาจากสไลด์ต้นฉบับ ไม่มีข้อมูลที่เพิ่มเอง
